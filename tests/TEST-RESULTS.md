- Defender 清理 .log 文件后保留非日志文件。
- 全选、取消全选、清理按钮状态、日志选择复制与全部复制、清空日志、深浅主题。
- 窗口关闭及退出菜单保存勾选项。

## 复现

在安装 .NET 桌面构建工具及 .NET Framework 4.8 目标包的开发者 PowerShell 中运行。

    msbuild tests/FunctionalTests.csproj /p:Configuration=Release
    ./tests/bin/Release/CleanSweep.FunctionalTests.exe

测试使用独立临时目录，创建、占用、删除测试文件，再清理本次测试目录。目录字段通过测试代码的反射替换，实际发布程序不提供这种测试入口。
